# DEVFORGE Student Support Knowledge Base

## About DEVFORGE

DEVFORGE is an AI engineering internship program where students gain practical experience by building real-world AI applications.

The internship focuses on learning through projects rather than theory.

---

## Internship Topics

Students learn:

- Python Programming
- FastAPI
- REST APIs
- Git & GitHub
- LangChain
- LangGraph
- Retrieval Augmented Generation (RAG)
- AI Agents
- Prompt Engineering
- Machine Learning Fundamentals
- Deployment using Render

---

## Projects

Students build projects including:

- AI Chatbots
- Student Support AI Agents
- Sentiment Analysis Systems
- RAG Applications
- API Based Applications

---

## FastAPI

FastAPI is a modern Python framework used to build REST APIs.

Benefits include:

- High performance
- Automatic Swagger documentation
- Data validation using Pydantic
- Easy deployment

---

## LangGraph

LangGraph is used to build AI workflows.

It allows developers to:

- Create multiple AI nodes
- Build conditional routing
- Manage conversation state
- Build AI agents

---

## LangChain

LangChain provides tools for:

- Prompt templates
- Retrieval
- Memory
- Document loading
- LLM integration

---

## RAG

Retrieval Augmented Generation combines:

- Knowledge Base
- Vector Database
- Embedding Model
- Large Language Model

Instead of relying only on the model's knowledge, relevant information is retrieved first and then given to the LLM.

---

## GitHub

GitHub is used for:

- Version control
- Source code management
- Collaboration
- Project hosting

Students should upload their complete project repository.

---

## Deployment

Projects are deployed using Render.

Before deployment:

- Push the project to GitHub.
- Ensure requirements.txt is present.
- Configure environment variables securely.
- Verify FastAPI runs locally.

---

## AI Agent

The DEVFORGE Student Support AI Agent helps students by answering questions related to:

- Python
- FastAPI
- LangGraph
- LangChain
- RAG
- GitHub
- Render
- Internship guidance

If information is not available in the knowledge base, the assistant should say it does not know.
